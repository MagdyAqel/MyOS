# MyOS 11

سطح مكتب تفاعلي عربي مستوحى من Windows 11، يعمل في المتصفح. يتضمن إقلاعًا مرئيًا، وقائمة ابدأ وشريط مهام ونوافذ، ومتصفحًا داخليًا ومفكرة متعددة الملاحظات ولعبة استراتيجية ثلاثية الأبعاد.

`Develped by:Pro. Magdy S. Aqel`

## التشغيل والبناء

المتطلبات: Node.js 20.19+ أو 22.12+ وnpm. تم التحقق باستخدام Node 24.

```sh
npm ci
npm run dev -- --port 5173
npm run build
```

النتيجة الثابتة في `dist/`. لا يتطلب التطبيق خدمات خلفية أو بيانات دخول. تستخدم البيئة السحابية مخبأ npm في `/workspace/.npm-cache` عند الحاجة: `npm ci --cache /workspace/.npm-cache`.

## الإقلاع وسطح المكتب

يظهر شعار MyOS 11 ومؤشر بدء التشغيل وعبارة المطوّر، ثم شاشة الترحيب وسطح المكتب تلقائيًا. يمكن تجاوز الانتظار بزر «الدخول الآن». النوافذ تدعم السحب والتكبير والتصغير والإغلاق. القفل وإعدادات الشبكة والسطوع محاكاة داخل الموقع.

## المفكرة وحفظ البيانات

- إنشاء عدة ملاحظات، وإعادة تسميتها والتنقل بينها.
- حفظ النص والعنوان والملاحظة النشطة فور الكتابة في `localStorage` على نفس المتصفح ونفس عنوان الموقع.
- استيراد الملاحظة القديمة من مفتاح `myos-note` تلقائيًا دون حذف الأصل.
- الاحتفاظ بآخر نسخة محلية سليمة لاستعادتها إذا تلف سجل الملاحظات الأساسي.
- تحديث الملاحظات بين التبويبات، وتنزيل الملاحظة الحالية بصيغة TXT.
- إظهار تنبيه واضح إذا تعذّر الحفظ بسبب امتلاء التخزين أو تعطيله.

الحفظ محلي لهذا المتصفح؛ لا توجد مزامنة سحابية أو استعادة بعد مسح بيانات الموقع، وقد تُحذف بيانات الوضع الخاص عند إغلاقه. نزّل نسخة نصية للبيانات المهمة.

## المتصفح الداخلي

يقبل روابط HTTPS ويدعم رجوع/تقدم العناوين المدخلة وإعادة التحميل والفتح الخارجي. تُعرض المواقع داخل iframe معزول. المواقع التي تمنع التضمين باستخدام CSP أو X-Frame-Options تحتاج زر «فتح خارجي»؛ لا يحاول التطبيق تجاوز سياساتها.

## قيادة الأفق 3D

لعبة استراتيجية أصلية مصغرة مستوحاة من أسلوب RTS، باستخدام Three.js وWebGL2. النماذج هندسية محلية، مع إضاءة وظلال وأشرطة صحة وكاميرا قابلة للتقريب والتدوير. لا تستخدم أصول Generals أو ملفاتها وليست اللعبة الأصلية.

| المرحلة | ساحة اللعب | الوحدات |
| --- | --- | --- |
| درع الصحراء | أرض صحراوية | جنود ودبابات |
| السيادة الجوية | مرتفعات ومطارات | مقاتلات وقاذفات وجنود |
| حارس المضيق | ساحل وبحر | مدمرات وغواصات ومقاتلات |
| أعماق صامتة | قاع بحر ومحطات مغمورة | غواصات ومدمرات |

- اختر المرحلة من القائمة؛ جميع المراحل متاحة للتجربة. تغيير المرحلة يبدأ مهمة جديدة.
- اختر مبنى وانقر موقعًا فارغًا، أو استخدم «بناء في مكان مقترح». في المراحل البحرية تُبنى منصات الدعم في القطاع العلوي، والميناء قرب الشاطئ.
- مركز الإمداد يمنح $180 كل خمس ثوانٍ. الإنتاج يحتاج محطة طاقة ومبنى التدريب المناسب. الحد الأقصى 40 وحدة صديقة.
- انقر وحدة لتحديدها وShift لإضافة وحدات، أو اضغط «تحديد الجيش». انقر الأرض للتحرك أو هدفًا أحمر للهجوم. زر «هجوم على مقر العدو» بديل للهاتف.
- الغواصات تهاجم السفن والغواصات بالطوربيدات، والمقاتلات لا تهاجم أهدافًا تحت الماء. المدمرات قادرة على قصف الساحل ومكافحة الغواصات.
- أزرار الكاميرا للتقريب والتدوير والعودة للمنظر العام والتركيز على الجيش. عجلة الفأرة للتقريب، والزر الأوسط أو إصبعان لتدوير الكاميرا.
- الفوز بتدمير قيادة العدو، والخسارة بسقوط قيادتك. زر «المرحلة التالية» يعمل بعد الفوز. تُحفظ المرحلة المختارة والمراحل المكتملة محليًا، لكن لا تُحفظ المعركة الجارية عند إغلاق نافذتها.
- المحاكاة تتوقف عند الإيقاف المؤقت أو تصغير النافذة أو قفل سطح المكتب أو إخفاء التبويب.
- يلزم WebGL2؛ عند غيابه أو فقدان سياق الرسومات يظهر تنبيه واضح. تُحمّل حزمة اللعبة عند فتحها لتبقى واجهة سطح المكتب خفيفة.

## الاختبارات

```sh
npm test
```

يشغّل الأمر اختبارات المحاكاة والحفظ باستخدام Node، ثم اختبارات Playwright للتطبيقات والهاتف والإقلاع والملاحظات وعرض WebGL والتنقّل بين المراحل واختيار النماذج ثلاثية الأبعاد. يستخدم الاختبار Chromium المثبت في `/usr/bin/chromium`؛ يمكن تحديد غيره بواسطة `PLAYWRIGHT_CHROMIUM_EXECUTABLE`.
