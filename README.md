# MyOS 11 · 3.0

سطح مكتب تفاعلي عربي مستوحى من Windows 11، يعمل في المتصفح وعلى الهاتف. يتضمن إقلاعًا مرئيًا وقائمة ابدأ ونوافذ ومتصفحًا داخليًا ومفكرة وملفات نصية ولعبة استراتيجية ثلاثية الأبعاد. يمكن تثبيته كتطبيق ويب والعمل بالمحتوى المحلي دون إنترنت.

`Develped by:Pro. Magdy S. Aqel`

الموقع: https://magdyaqel.github.io/MyOS/

## التشغيل والبناء

المتطلبات: Node.js 20.19+ أو 22.12+ وnpm؛ تم التحقق باستخدام Node 24.

```sh
npm ci
npm run dev -- --port 5173 --strictPort
npm run build
```

توجد النسخة الثابتة في `dist/`. تعمل الميزات المحلية دون خادم أو حساب. المزامنة بين الأجهزة اختيارية وتحتاج مشروع Supabase خاصًا بك. في البيئة السحابية يمكن استخدام `npm ci --cache /workspace/.npm-cache --no-audit --no-fund`.

## الإقلاع وسطح المكتب والهاتف

يظهر شعار MyOS ومؤشر التشغيل واسم المطوّر ثم سطح المكتب تلقائيًا؛ زر **الدخول الآن** يتجاوز الانتظار. تدعم النوافذ السحب والتكبير والتصغير والإغلاق، مع إعدادات للشكل والخلفية. القفل والشبكة والسطوع محاكاة داخل الموقع.

الهاتف يعرض شبكة تطبيقات ونوافذ تملأ المساحة وشريط مهام قابلًا للتمرير. أزرار اللمس تراعي الحجم والمساحات الآمنة، وتتكيف الواجهة مع الاتجاه وتغيّر مساحة العرض. في اللعبة تظهر لوحتا **بناء وتدريب** و**الخرائط والصوت** عند الحاجة وتبقى أوامر التحديد والهجوم قريبة من الميدان.

من **الإعدادات → صور سطح المكتب** اختر الجبال أو الشاطئ أو الكثبان أو الألوان المرفقة. يمكن رفع صورة PNG/JPEG/WebP حتى 12 ميغابايت؛ تُجهّز حتى 2048 بكسل وتُحفظ صورة شخصية واحدة محليًا في IndexedDB دون رفعها إلى خادم. الصور المرفقة رسومات SVG محلية.

## المفكرة والملفات

- المفكرة تدعم ملاحظات متعددة بعناوين، والبحث داخل العنوان والنص، والتنزيل بصيغة TXT. تحفظ الكتابة فورًا مع نسخة محلية سليمة للاسترداد، وتحدّث التبويبات الأخرى. تستورد الملاحظة القديمة من `myos-note` دون حذف الأصل.
- مستكشف الملفات يدعم إنشاء مجلدات وملفات نصية وتحرير النص وإعادة تسمية الملف والبحث والاستيراد والتنزيل. حد الاستيراد 500 كيلوبايت للملف؛ حد المجموعة 250 عنصرًا وحوالي 1.5 مليون حرف مخزّن.
- نقل الملفات والمجلدات إلى السلة قابل للتراجع، والحذف الدائم يحتاج تأكيدًا. استعادة مجلد تحفظ العناصر التي حُذفت سابقًا في السلة وتغيّر الاسم عند تعارضه.
- تظهر أخطاء الحفظ عند امتلاء التخزين أو تعطيله. البيانات محلية لنفس المتصفح وعنوان الموقع، وقد تُفقد عند مسح بيانات الموقع أو إغلاق الوضع الخاص. نزّل نسخة من البيانات المهمة.

## المتصفح الداخلي

يدعم عناوين HTTPS والرجوع والتقدم وإعادة التحميل والفتح الخارجي. يعرض الصفحات في iframe معزول؛ المواقع التي تمنع التضمين باستخدام CSP أو X-Frame-Options تحتاج زر **فتح خارجي**. المواقع الخارجية تحتاج اتصالًا حتى عند تثبيت MyOS.

## قيادة الأفق 3D

لعبة RTS أصلية مصغرة تستخدم Three.js وWebGL2. تتضمن نماذج هندسية وإضاءة وظلالًا وصحة وقذائف ودخانًا وآثار حركة وماءً متحركًا. الأسلوب مبسّط ولا يستخدم أصول Generals أو ملفاتها.

| المرحلة | الوحدات | المهام المتاحة |
| --- | --- | --- |
| درع الصحراء | جنود ودبابات | تدمير القيادة، حماية القافلة، إنقاذ ثلاثة فرق |
| السيادة الجوية | مقاتلات وقاذفات وجنود | تدمير القيادة، اعتراض ست طائرات خلال 180 ثانية |
| حارس المضيق | مدمرات وغواصات ومقاتلات | تدمير القيادة، السيطرة على ميناء لمدة 15 ثانية |
| أعماق صامتة | غواصات ومدمرات | تدمير القيادة، حماية المحطة لمدة 150 ثانية |

توجد ثماني خرائط، خريطتان لكل مرحلة. التضاريس تمنع البناء وتغيّر مسارات الوحدات وتحجب الرمي الأرضي، بينما تتجاوزها الطائرات. اختر نوع المهمة ومستوى الصعوبة **سهل/متوسط/صعب** من لوحة الخرائط. تغيير المرحلة أو الخريطة أو المهمة أو الصعوبة يبدأ معركة جديدة؛ احفظ أولًا إذا أردت الرجوع.

**البناء والتحكم:** اختر مبنى ثم موقعًا فارغًا، أو **بناء في مكان مقترح**. في البحر تكون منشآت الدعم أعلى الخريطة والميناء عند الشاطئ. مركز الإمداد يمنح $180 كل خمس ثوانٍ؛ الإنتاج يتطلب طاقة ومبنى تدريب مناسبًا. الحد الأقصى 40 وحدة صديقة. انقر وحدة ثم الأرض للتحرك أو العدو للهجوم؛ Shift يضيف إلى التحديد. توجد أزرار **تحديد الجيش** و**هجوم على مقر العدو** ولمس متعدد للتحديد.

**العدو والقتال:** يملك العدو موارد ودخلًا ويبني الطاقة والإمداد ومصنعًا أو مطارًا أو ميناءً وينتج تعزيزات، بجانب موجات المرحلة. تتنوع الأوامر بين مهاجمة القيادة والالتفاف وضرب الإمداد عند كشفه، وتتغير سرعة الاقتصاد والقرارات وحد الإنتاج مع الصعوبة. هذه قواعد تكتيكية محلية. ضباب الحرب يخفي الوحدات المعادية حتى تستكشفها؛ يمكن إيقافه. الذخيرة محدودة للوحدات المتحركة، وتعود تلقائيًا عند نفادها. زر **عودة للصيانة والتسليح** يعيد الجيش المحدد لأقرب مقر/إمداد/ميناء؛ إعادة الذخيرة مجانية والإصلاح يكلف $5 لكل 25 نقطة صحة في الثانية. تختلف الأهداف المسموحة للطائرات والسفن والغواصات.

**الحفظ:** زر **حفظ المعركة** يسجل الوحدات والصحة والذخيرة والأوامر والموارد والاقتصاد والهدف والخريطة والمناطق المستكشفة. يوجد حفظ تلقائي كل عشر ثوانٍ من المحاكاة وعند الإخفاء أو الإغلاق. زر **استئناف آخر حفظ** يختار أحدث حفظ صالح ويعيده متوقفًا لتراجع الميدان ثم تضغط **متابعة**. تُحفظ أيضًا المراحل المكتملة والخريطة المختارة. توقف المحاكاة عند التصغير أو القفل أو إخفاء التبويب، وتُبلّغ أخطاء التخزين.

**الكاميرا والصوت:** عجلة الفأرة للتقريب، والزر الأوسط أو إصبعان للتدوير، والسحب بإصبع واحد لتحريك الميدان. توجد أزرار للمنظر العام والتركيز والخريطة المصغرة. شغّل الصوت صراحة من داخل اللعبة: مؤثرات مركّبة محليًا للأسلحة والانفجارات والسونار والتنبيهات والمحركات، مع حفظ مستوى الصوت وكتمه عند التوقف. لا توجد تسجيلات مأخوذة من Generals.

يلزم WebGL2 للعبة. يظهر تنبيه عند غيابه أو فقدان السياق؛ تستخدم الهواتف دقة وظلالًا أخف. حزمة اللعبة تُحمّل عند فتحها، ويخزّنها وضع عدم الاتصال مسبقًا.

## التثبيت والعمل دون إنترنت

افتح تطبيق **تثبيت التطبيق** وانتظر رسالة **المحتوى المحلي جاهز للعمل دون إنترنت** وأنت متصل. يخزّن Service Worker ملفات نسخة البناء، بما فيها اللعبة والخرائط والخلفيات والأيقونات. بعدها يمكن إعادة تحميل الموقع والعمل بالمفكرة والملفات واللعبة دون شبكة. لا تُخزّن صفحات المتصفح الخارجي أو اتصالات المصادقة أو بيانات السحابة في ذاكرة Service Worker.

على Android استخدم زر التثبيت أو قائمة المتصفح. على iPhone/iPad افتح Safari ثم **مشاركة → إضافة إلى الشاشة الرئيسية**. يتطلب Service Worker نشر HTTPS؛ لا يسجّل في خادم التطوير. عند توفر نسخة جديدة يظهر زر **تطبيق التحديث المتاح**. لا تمسح بيانات الموقع للحصول على التحديث لأن ذلك يمسح بياناتك المحلية.

## المزامنة الاختيارية

تطبيق **المزامنة السحابية** مجهّز لتسجيل البريد وكلمة المرور ورفع واستعادة الملاحظات والملفات وحفظ المعارك وتقدّم المراحل يدويًا. يراجع المستخدم العملية قبل التأكيد، ويرفض الرفع فوق إصدار أحدث، ويحتفظ بتراجع محلي عند الاستعادة. تُغلق التطبيقات الأخرى قبل تطبيق النسخة المستعادة حتى لا تكتب حالتها القديمة فوقها.

لم يتم ربط مشروع Supabase حقيقي بهذا المستودع. اتبع [دليل إنشاء المشروع وربطه](supabase/README.md) ونفّذ [سياسات SQL](supabase/schema.sql)، ثم أدخل عنوان المشروع والمفتاح **العام** في التطبيق. لا تضع كلمة مرور قاعدة البيانات أو مفتاح service_role في الموقع. لا تُرفع الخلفية الشخصية أو كلمات المرور أو الجلسات، وتبقى جلسة الدخول في الذاكرة فقط.

## الاختبارات

```sh
npm test
npm run test:production
```

الأول يشغّل اختبارات Node للمحاكاة والحفظ والملفات وعميل المزامنة، ثم Playwright لسطح المكتب والمفكرة والهاتف والخرائط والصوت وعرض WebGL. الثاني يبني الموقع ويختبره تحت `/MyOS/` بما فيه إعادة التحميل والعمل باللعبة والملاحظات دون شبكة. يستخدم Chromium في `/usr/bin/chromium`، ويمكن تحديد بديل بواسطة `PLAYWRIGHT_CHROMIUM_EXECUTABLE`.

اختبارات الهاتف تشمل أبعاد 320×640 و390×844 و844×390 ولمسًا محاكى وتقلّص المساحة؛ لا تحاكي لوحة مفاتيح iOS/Android الأصلية. اختبارات السحابة تستخدم خدمة محاكاة؛ لم تُختبر خدمة Supabase فعلية أو تثبيت على جهاز مادي ضمن هذا التحديث.

## النشر

يبني `.github/workflows/pages.yml` الموقع وينشر `dist/` عند الرفع إلى `main` بعد نجاح اختبارات Node. اختر **Settings → Pages → Source → GitHub Actions**. المسارات نسبية وتدعم `/MyOS/`. للنشر اليدوي على Cloudflare Pages أو استضافة ثابتة، ارفع محتويات `dist/` بعد البناء، بما فيها `sw.js` وملف manifest.
